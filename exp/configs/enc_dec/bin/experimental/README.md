# Experimental Encoder-Decoder Configs

This directory archives exploratory encoder-decoder configs that were useful during development but are not the primary baseline configs.

Contents include:

- `constant_seq/`: constant-sequence and history/previous-context experiments.
- `rl/`: RL/shared-KV fine-tuning experiments.
- `gencontext.yaml`: generated-context experiment config.

Some scripts in this archive may still reference older module choices or absolute paths. Check paths and environment setup before rerunning them.
