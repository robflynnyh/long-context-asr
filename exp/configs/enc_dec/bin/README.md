# Encoder-Decoder Archived Configs

This folder contains older encoder-decoder launch configs and scripts that are not the main baseline reference set.

Use `../masking.yaml`, `../0_873621.yaml`, and `../enc_dec_test.yaml` first when looking for the trained 2048-context encoder-decoder checkpoints documented in `../README.md`.

`experimental/` contains moved one-off experiments such as constant-sequence history variants, RL/shared-KV variants, and generated-context configs.
